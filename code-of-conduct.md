# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive in issues, pull requests, and reviews.
- Critique the submission, not the person.
- No harassment, personal attacks, or discriminatory language.
- Do not publish anyone's private information.

Maintainers may edit, hide, or remove contributions that break these rules, and may block repeat offenders.

To report a problem, [open an issue](../../issues) or contact a maintainer privately through their GitHub profile.
